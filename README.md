رائد أعمال مقيم في الرياض، أعمل على تقاطع ثلاثة مجالات: **تصميم العلامات التجارية والهوية البصرية**، و**تطوير تطبيقات الموبايل (Flutter & Firebase)**، و**تحليل الأسواق المالية**. أؤمن بأن المنتج الجيد يبدأ من هوية واضحة وينتهي بتنفيذ تقني نظيف.

## المشاريع

### مشروع ختام دورة السلاسل الزمنية — SDAIA
**تحليل وتنبؤ بركاب الطيران الدولي 1949–1960**

خط أنابيب كامل لتحليل السلاسل الزمنية: تشخيص السلسلة، تحديد أرضية أساس (Seasonal Naive)، تصفية النماذج عبر AutoGluon، ومحك تدقيق بثماني نوافذ متدحرجة (Rolling-Origin Cross-Validation). النتيجة: نموذج **AutoARIMA** يقلّص خطأ الأرضية إلى النصف (MASE 0.66 مقابل 1.31) — مع تقرير إداري كامل وصفحة عرض مستقلة.
